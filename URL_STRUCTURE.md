# Preferred URL Structure

## City + service

`/{service}-in-{city}/`

Example: `/invisible-grills-in-chennai/`

## Area + service

`/{service}/{state}/{city}/{area}/`

Example: `/safety-nets/tamil-nadu/chennai/adyar/`

## Legacy redirects

- `/{city}/{service}/` → `/{service}-in-{city}/`
- `/{city}/{area}/{service}/` → `/{service}/tamil-nadu/{city}/{area}/`
